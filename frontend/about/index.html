About MathNova

MathNova is an engineering-mathematics engine with a web interface. It solves the problems an engineering syllabus sets, and checks each answer before showing it.

The idea

Most tools that do symbolic mathematics give you an answer and leave the checking to you. That is fine when you already know what the answer should look like, and useless when you do not — which is exactly when you reached for the tool.

So every MathNova engine verifies its own work by an independent route. A solved differential equation is substituted back into the original operator and the residual must come out zero. An inverse transform is transformed forward again and compared. A linear system’s solution is re-multiplied by its matrix. A derivative is re-derived implicitly. When a check passes, the result says so; when an engine cannot verify something, it says that instead of presenting an unchecked answer as fact.

This is not a formality. Several genuine errors — a dropped factor in a Z-transform, a wrong binomial coefficient for a repeated pole — were caught by these checks during development, in results that looked entirely reasonable.

How it is built

Mathematics
Pure Python engines over SymPy, NumPy and SciPy, with no web framework imports. They are covered by their own test suite and are unchanged by anything in the interface.
API
A FastAPI layer that validates input, calls an engine, and serialises the result to both plain text and LaTeX. It is documented at /api/docs.
Interface
Static HTML, CSS and JavaScript — no build step and no framework. Mathematics is typeset with KaTeX.
Assistant
Provider-agnostic. The model is given tools that call the verified engines, and is instructed to use them rather than compute anything itself.
Safety
Each calculation runs in its own short-lived process under a time limit and a memory cap, so no single expression can hang the service.

Scope of V1
